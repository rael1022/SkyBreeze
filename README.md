SkyBreeze is a beginner-friendly, multi-page Korean learning website created for **LMPU3282 Korean for Beginners**. Its sky-and-travel theme turns Lesson 4 place vocabulary, grammar, quizzes and role-play conversations into a light interactive learning journey.

## About

**Fly Beyond Clouds, Discover Korean.**

SkyBreeze helps learners practise practical Korean for asking where places are and describing everyday locations. Learners move through vocabulary clouds, grammar breezes, game-style practice and short conversation flights. The website uses a clean sky-blue visual style with clouds, route maps, gentle animations and responsive layouts to make Korean learning feel welcoming and memorable.

## Features

- Seven independent HTML pages with shared navigation and a SkyBreeze favicon/logo.
- 18 Korean place vocabulary words: six members, three words per member.
- Korean words, romanisation, English translations and contextual Korean example sentences.
- Grammar patterns for `N에 가요 / 와요` and `N에 있어요 / 없어요`, plus visual location-word diagrams.
- Interactive Practice Sky quiz with feedback, score counter, restart button and flip flashcards.
- Local Wayground Quizzes QR code and direct activity link.
- Three Korean role-play dialogues, each with three speakers, six Korean lines and English translations.
- Video modal slots for student face-and-voice recordings.
- Responsive layout and reduced-motion support.

## Pages

| Page | Purpose |
| --- | --- |
| `index.html` | Landing page and learning route map |
| `vocabulary.html` | Six three-word vocabulary sets |
| `grammar.html` | Grammar and location-word visuals |
| `practice.html` | Quizzes, flashcards and Wayground QR |
| `conversation.html` | Three three-speaker role plays |
| `crew.html` | Team members and project roles |
| `final.html` | Completion and thank-you page |

## Run locally

No installation or build process is needed. Open `index.html` in a browser, or use a local static-server extension such as Live Server in VS Code.

## Built with

HTML5, CSS3 and vanilla JavaScript.
